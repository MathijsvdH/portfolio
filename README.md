# Island Portfolio

Mathijs's portfolio as an interactive 3D island, built with React Three Fiber.

## Run
```
npm install
npm run dev
```
Open http://localhost:5173.

## Working with Claude Code
Rules for the agent are in `CLAUDE.md`. Progress is logged in `docs/devlog.md`,
choices in `docs/decisions.md`, zone status in `docs/zones.md`.
